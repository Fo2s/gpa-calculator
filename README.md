# GPA Calculator

A tiny open-source GPA calculator built with plain HTML, CSS, and JavaScript.

## Features

- Add and remove courses
- Enter credit hours
- Choose letter grades
- See GPA, total credits, and course count instantly
- Runs locally with no build step

## Usage

Open `index.html` in your browser.

## Grade Scale

The calculator uses a standard 4.0 scale:

| Grade | Points |
| --- | ---: |
| A+ | 4.0 |
| A | 4.0 |
| A- | 3.7 |
| B+ | 3.3 |
| B | 3.0 |
| B- | 2.7 |
| C+ | 2.3 |
| C | 2.0 |
| C- | 1.7 |
| D+ | 1.3 |
| D | 1.0 |
| F | 0.0 |
