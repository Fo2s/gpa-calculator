# GPA Calculator

A tiny open-source GPA calculator built with plain HTML, CSS, and JavaScript.

## Features

- Add and remove courses
- Enter credit hours
- Choose letter grades
- See GPA, total credits, and course count instantly
- Switch between US and German grading scales
- Export grades and summary results as a CSV file
- Toggle light and dark mode
- Runs locally with no build step

## Usage

Open `index.html` in your browser.

## Grade Scales

The calculator supports a standard US 4.0 scale:

| Grade | Points |
| --- | ---: |
| A+ | 4.0 |
| A | 4.0 |
| A- | 3.7 |
| B+ | 3.3 |
| B | 3.0 |
| B- | 2.7 |
| C+ | 2.3 |
| C | 2.0 |
| C- | 1.7 |
| D+ | 1.3 |
| D | 1.0 |
| F | 0.0 |

It also supports a German 1.0-5.0 scale, where 1.0 is the strongest grade:

| Grade | Points |
| --- | ---: |
| 1.0 | 1.0 |
| 1.3 | 1.3 |
| 1.7 | 1.7 |
| 2.0 | 2.0 |
| 2.3 | 2.3 |
| 2.7 | 2.7 |
| 3.0 | 3.0 |
| 3.3 | 3.3 |
| 3.7 | 3.7 |
| 4.0 | 4.0 |
| 5.0 | 5.0 |
